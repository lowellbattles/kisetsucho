季節帳 — icon rasterizer

Renders the app icon to PNG at every size the manifest and iOS need. For each icon below: click the download link and save the file into public/icons/ under the shown name, or copy its base64 out of the textarea. Needs a system Japanese mincho font for a faithful 季 glyph (Windows: Yu Mincho / macOS & iOS: Hiragino Mincho ProN — both ship with the OS).
